HOW TO PLAY

📈 Objective

Start with $10,000 and maximize your portfolio value over 50 turns. Beat the market return to prove your trading skills!

💹 Trading Actions

  • BUY - Purchase shares (go long, profit when price rises)
  • SELL - Sell shares you own
  • SHORT - Borrow & sell shares (profit when price falls)
  • COVER - Buy back shorted shares to close position

📊 Key Indicators

  • RSI - Below 30 = oversold (buy signal), Above 70 = overbought (sell signal)
  • Momentum - Positive = uptrend, Negative = downtrend
  • Beta - >1 = more volatile than market, <1 = more stable
  • Fear/Greed - Low = fear (buying opportunity), High = greed (bubble risk)

⚠️ Risks

  • Transaction fees (1%) apply to all trades
  • Short positions have borrowing costs and margin calls
  • Market crashes and crises can happen suddenly
  • News can be misleading - not all signals are accurate

⌨️ Keyboard Shortcuts

  • B - Select Buy
  • S - Select Sell
  • H - Select Short
  • C - Select Cover
  • Enter - Execute Trade
  • Ctrl+Enter - Next Turn
  • Ctrl+S - Save Game
